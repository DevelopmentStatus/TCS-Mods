An easier way to use mods in LEGO Star Wars: The Complete Saga.[/center]

[line]

[b][size=4]About this mod[/size][/b]
TCS Mod Loader lets you add supported mods by putting their ZIP or RAR files into one folder. It can load character packs, character replacements, extra levels, music and more, along with plugins made for this loader.

You can turn supported mods on or off, change their settings, and choose which mod takes priority when two mods change the same files. Your original game DAT files stay untouched.

[b][size=4]What it does[/size][/b]
[list]
[*]Loads supported mod ZIP and RAR files without you having to unpack them.
[*]Works with supported character packs, replacements, level packs, music and other game files.
[*]Works out where supported mod files belong, including some packs with loose files or unusual folders.
[*]Adds characters to the character list and shop when a supported pack includes the needed information.
[*]Lets you choose between different looks included in supported character packs.
[*]Includes a load-order window where you can drag mods into order, turn them on or off, and see which ones change the same files.
[*]Automatically runs Auto-sort and saves when overlapping enabled mods have matching priorities, then continues game startup.
[*]Keeps your saved custom order when priorities are distinct. The Auto-sort button is still available if you want a new suggestion.
[*]Adds a Mod Settings menu to the pause menu for supported mods.
[*]Shows a preparation window while getting your mods ready. If nothing has changed, it reuses the files it already prepared.
[*]No separate Python or QuickBMS download is needed.
[/list]

[b][size=4]How to install[/size][/b]
[list=1]
[*]Close the game.
[*]Open the game folder. This is the folder with [b]LEGOStarWarsSaga.exe[/b] in it.
[*]If that folder already has a [b]d3d9.dll[/b] file, make a backup of it first.
[*]Download the loader ZIP from the [url=https://www.nexusmods.com/legostarwarsthecompletesaga/mods/213?tab=files]Files tab[/url].
[*]Open the downloaded ZIP to see the files inside. If you cannot open it, you can install a program such as 7-Zip or WinRAR. I recommend [url=https://7-zip.org/download.html]7-Zip[/url].
[*]Select all the files and folders inside the loader ZIP, then drag and drop them into the game folder. [b]d3d9.dll[/b], [b]TCSAssetManager.exe[/b] and [b]Manage Mod Priorities.cmd[/b] should be beside LEGOStarWarsSaga.exe.
[*]Put your supported mod ZIP or RAR files directly into the [b]Mods[/b] folder. Leave them zipped.
[*]Start the game as usual. Large mods can take a few minutes to get ready the first time, or after you change them.
[/list]
[b]Updating from an older version?[/b] Close the game and replace both d3d9.dll and TCSAssetManager.exe. Keep your mod downloads and saved settings.

[b][size=4]Choosing which mod loads last[/size][/b]
In version 1.6.6, if enabled mods change the same files and have matching priority numbers, the loader automatically runs [b]Auto-sort[/b], saves the order and continues starting the game. You do not need to click Auto-sort or Save settings for this step.

Already saved a custom order with different priority numbers? The loader keeps it. To choose your own order, close the game and double-click [b]Manage Mod Priorities.cmd[/b]. Any matching priorities on overlapping mods are also sorted and saved automatically when you open this window.

Drag mods into order or use the arrow buttons. [b]A higher priority number means a mod loads later.[/b] If two mods replace the same file, the one that loads later usually wins.

[b]Example:[/b] To use a Boba Fett replacement over another character pack, put the Boba Fett mod below that pack and give it a higher priority number, such as 200 for Boba Fett and 100 for the other pack. Save your changes. Boba Fett will win where both mods replace the same files.

[list]
[*][b]Auto-sort[/b] recalculates the suggested order, usually putting large packs before smaller replacements. Save after clicking it manually. Always follow the mod author's instructions too; Auto-sort cannot know which character replacement you prefer or every mod's requirements.
[*][b]Save settings[/b] saves your changes and keeps the window open.
[*][b]Launch game[/b] saves your changes and starts the game, or continues the game if it is already waiting for you.
[*]Closing without saving discards your manual edits. Any order already saved by automatic sorting remains saved.
[/list]
The editor opens during startup if an import error or failed automatic save needs attention. Matching priorities alone are handled automatically. You can still open the editor yourself at any time with the game closed.

[b][size=4]In-game settings[/size][/b]
Open [b]Pause > Mod Settings[/b] to see the settings offered by your installed mods. Restart the game after changing an asset mod's on/off setting, priority or character look.

[b][size=4]Which mods work?[/size][/b]
The loader has been checked with the Steam version of the game on 64-bit Windows 10 and 11. Other game versions have not been checked.

It supports the file layouts used by:
[list]
[*]Additional Levels 2.3.1
[*]Additional Levels for Modern Overhaul 1.4
[*]Modern Overhaul 2.2.2
[*]The Mandalorian Season 2 Character Pack
[*]Clones
[/list]
[b]Support is not limited to these names.[/b] Other mods with similar supported files and folders can work too. Some mods still need extra support, and being able to load two mods does not mean they will work together perfectly.

[list]
[*]Install only one version of Additional Levels. The Modern Overhaul version needs Modern Overhaul installed, with Additional Levels loading after it.
[*]Always check whether a mod needs another mod to work. Put addons after the mod they depend on.
[*]Some character information can be combined. Level packs may replace shared files completely, so changing the order cannot fix every conflict.
[*]The conflict list shows mods that change the same game files. It cannot find every problem between plugins or tell you about every missing requirement.
[*]Mods that come with their own d3d9.dll may clash with this loader. Read their instructions before replacing that file.
[*]Mods larger than 8 GiB when unpacked, or containing a single file larger than 512 MiB, exceed the loader's limits.
[*]Other people's mods are not included. Download them separately from their authors.
[/list]

[b][size=4]Help and common questions[/size][/b]
[spoiler]
[b]Steam says the game is running, but I cannot see it[/b]
Look for the preparation window or load-order window. A large mod pack can take a few minutes to get ready. Version 1.6.4 fixes unnecessary repeat work that could make startup much slower. Make sure you replaced both loader files when updating.

[b]Manage Mod Priorities.cmd reports an asset import error[/b]
Version 1.6.5 opens the editor before extracting assets. Failed archives appear in the list with an Import error label. Select one to read the reason, then disable it and save or replace its download. Saving or closing the manual editor does not rebuild assets. If you need help, send the [b]report.json[/b] named in the error as well as the logs.

[b]My new characters are not in the shop[/b]
Make sure the character pack is turned on and that you installed everything it needs. Another mod may be replacing the files it uses. Check the load order and restart after changing it. Some packs still need extra support before their characters can appear in the shop.

[b]I see the wrong character model or replacement[/b]
Check which mods change the same files in the load-order window. Give the mod you want to use a higher priority number. If it offers different looks, check which one you selected.

[b]The load-order window does not open when I start the game[/b]
Version 1.6.6 automatically sorts and saves overlapping mods with matching priorities, then continues startup. Saved distinct priorities keep your custom order. To open the editor yourself, close the game and double-click Manage Mod Priorities.cmd.

[b]The loader is using a lot of disk space[/b]
The loader keeps prepared files, including older copies. Updating does not remove those automatically. With the game and TCSAssetManager closed, you can delete [b]Mods/Assets[/b] to clear its saved files. The loader will prepare them again next time. Keep [b]Mods/Config[/b] and your mod ZIP/RAR files. Do not delete the whole game folder.

[b]A mod will not load[/b]
Check the mod author's instructions and make sure you have any other mods it needs. For help, include the mod's name and version, plus [b]Mods/Assets/import.log[/b] and [b]TCSModernOptions.log[/b] when reporting the problem.
[/spoiler]

[line]

[b][size=4]Removing mods[/size][/b]
Close the game, remove the mod's ZIP or RAR file from Mods, then start the game again. The loader will prepare the remaining mods.

To remove the loader itself, close the game and remove its d3d9.dll, TCSAssetManager.exe and Manage Mod Priorities.cmd. Restore your old d3d9.dll if you backed one up. Keep any mods or settings you want to save.
