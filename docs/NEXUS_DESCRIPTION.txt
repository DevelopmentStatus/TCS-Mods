[b][size=4]About this mod[/size][/b]
TCS Mod Loader imports supported asset mods from ZIP and RAR files and loads native plugins made for this loader. Use it for supported character replacements, character packs, extra levels, music and other game assets. Original game DAT files stay untouched.

Choose which asset mod wins when files overlap, then open [b]Pause > Mod Settings[/b] to change settings offered by installed mods.

[b][size=4]What changed in 1.8.0?[/size][/b]
[list]
[*][b]Character/shop expansion is now a separate optional mod.[/b] The loader ZIP does not include Character & Shop Extender. Install its compressed ZIP in Mods when your character packs need expanded tables, private names or extended portrait support.
[*]The extender preserves up to 1,000 registered characters and shop entries, expanded text/portrait tables and existing companion-save support. Normal story requirements and stud prices still apply.
[*][b]Prepare mods before starting the game.[/b] Use Manage Mod Priorities.cmd and choose Launch game, or run Prepare Mods.cmd before launching normally. Repeat after changing archives or asset settings.
[*]Keep the complete [b]TCSAssetRuntime[/b] folder beside TCSAssetManager.exe. No separate Python or QuickBMS installation is needed.
[*]Saga Tweaks / ASI integration has been removed. The earlier built-in support for running Saga Tweaks without Universal ASI Loader is no longer provided.
[/list]
[b]Existing saves:[/b] The separate extender uses the same [b].tcs-characters[/b] companion format as the previous built-in extender. Keep native saves and their companions together. Updating does not automatically unlock characters. Removing or updating the extender requires closing the game.

[b][size=4]How to install or update[/size][/b]
[list=1]
[*]Close the game and open the folder containing [b]LEGOStarWarsSaga.exe[/b].
[*]Back up any existing [b]d3d9.dll[/b]. Multiple mods cannot use that same filename at once; compatibility with other proxy DLLs has not been established.
[*]Download [url=https://github.com/DevelopmentStatus/TCS-Mods/releases/tag/TCSModLoader-v1.8.0]loader 1.8.0 from GitHub Releases[/url]. Extract [b]all[/b] its files and folders into the game folder. d3d9.dll, TCSAssetManager.exe, Prepare Mods.cmd, Manage Mod Priorities.cmd and the complete TCSAssetRuntime folder belong beside the game EXE.
[*]Put supported mod ZIP/RAR files directly in [b]Mods[/b]. Keep mod archives compressed.
[*]For character packs requiring the extender, download [url=https://github.com/DevelopmentStatus/TCS-Mods/releases/tag/TCSCharacterShopExtender-v1.0.0]Character & Shop Extender 1.0.0[/url] and put that ZIP directly in Mods. [b]Do not extract the extender ZIP.[/b]
[*]Run [b]Manage Mod Priorities.cmd > Launch game[/b], or run [b]Prepare Mods.cmd[/b] and then launch the game normally. Large packs may take several minutes on first preparation.
[/list]
Keep your existing mod downloads, Mods/Config settings, native saves and companion saves when updating. Replace the loader files and bundled runtime together. Repeat preparation after adding, removing or replacing archives, or changing asset settings.

[b]Missing extender message?[/b] Install its ZIP in Mods and prepare again. The loader refuses dependent character overlays if the extender is missing or fails to initialize.

[b][size=4]Choosing which asset mod loads last[/size][/b]
With the game closed, open [b]Manage Mod Priorities.cmd[/b]. Drag mods into order or use the arrow buttons. [b]A higher priority number means an asset mod loads later.[/b] If two mods replace the same file, the later one usually wins.

For example, give your preferred Boba Fett replacement priority 200 and a larger character pack priority 100 to let the replacement win their shared files.

[list]
[*]When overlapping enabled mods have matching priorities, preparation automatically runs Auto-sort and saves the order. Distinct saved priorities preserve your custom order.
[*][b]Auto-sort[/b] suggests an order, usually putting larger packs before smaller replacements. Save after manually changing it. Follow each mod author's requirements; sorting cannot resolve every conflict.
[*][b]Save settings[/b] saves changes and keeps the window open. Saving or closing the manual editor does not rebuild assets.
[*][b]Launch game[/b] saves settings, prepares the enabled selection and starts the game.
[*]Closing without saving discards manual edits. Any order already saved by automatic sorting remains saved.
[/list]

[b][size=4]In-game settings[/size][/b]
Open [b]Pause > Mod Settings[/b] for settings offered by installed plugins. After changing an asset mod's enabled state, priority or character look, close the game, prepare again, then restart.

[b][size=4]Supported mods and requirements[/size][/b]
Targets the validated 32-bit Windows Steam PC game. Other game editions and executable revisions have not been validated.

The importer supports the layouts used by Additional Levels 2.3.1, Additional Levels for Modern Overhaul 1.4, Modern Overhaul 2.2.2, The Mandalorian Season 2 Character Pack, Clones, Clone Trooper Expansion 1, Obi Wan Kenobi Expansion 1, and Anakin Skywalker Expansions 1 and 2. Character packs may require the separate extender. Other mods with supported layouts can work too; importing two packs does not guarantee they are compatible.

[list]
[*]Use only one Additional Levels variant. The Modern Overhaul variant also requires Modern Overhaul and should load after it.
[*]Other people's mods are not included. Download them separately from their authors.
[*]The conflict list shows shared asset files. It cannot identify every plugin conflict or missing requirement.
[*]Some character data can be merged; level packs may replace entire shared files. Load order cannot resolve every conflict.
[*]Archives larger than 8 GiB unpacked, or containing a file larger than 512 MiB, exceed the importer's limits.
[*]The loader does not provide built-in Saga Tweaks / ASI loading in this version.
[/list]

[b][size=4]Help and common questions[/size][/b]
[spoiler]
[b]My new characters are missing, misnamed or have blank portraits[/b]
Install the optional Character & Shop Extender ZIP, enable the relevant character packs and prepare again. Check the selected character variant and overlapping packs. Story unlocks and shop purchases still apply. Unsupported packs may need additional support.

[b]I used the built-in extender in an older loader[/b]
Install the separate extender ZIP to retain expanded character/shop and companion-save functionality with 1.8.0. Keep native saves and .tcs-characters companions together. Do not delete companions when backing up or transferring progress.

[b]The priority manager reports an import error[/b]
Select the failed archive to read its error. Disable it and save, or replace its download. Launch game prepares the enabled selection. If reporting a problem, include the mod name/version, report.json named in the error, Mods/Assets/import.log and TCSModernOptions.log where available.

[b]My changed mods are not appearing[/b]
Close the game and run Prepare Mods.cmd, or use Manage Mod Priorities.cmd > Launch game. The loader reads the prepared files; starting the game directly does not prepare changed archives for you.

[b]The loader uses a lot of disk space[/b]
Prepared assets include cached generations. With the game and manager closed, you can remove Mods/Assets to clear that cache, then prepare again. Keep Mods/Config, mod archives and saves.

[b]Will every mod combination work?[/b]
No. Check each author's instructions and requirements. Overlapping shared files and incompatible native plugins can still cause problems even when imports succeed.
[/spoiler]

[b][size=4]Removing mods[/size][/b]
Close the game, remove the relevant mod archive from Mods, prepare again, then launch. Removing the extender disables its expanded support and dependent character overlays; existing saves and companions are left intact.

To remove the loader, close the game and remove its d3d9.dll, TCSAssetManager.exe, TCSAssetRuntime folder and helper CMD scripts. Restore your earlier d3d9.dll if needed. Keep any mods, settings and saves you want to preserve.
