TCS Modern Options 0.4.0

Requires TCS Mod Loader. Put this ZIP in the game folder\Mods and restart.
Pause the game, choose Mod Settings below Effects Settings, then select TCS Modern Options to open its settings.
This optional plugin registers resolution, window mode, VSync and frame-cap settings.
The loader draws and controls the settings menu; F10 is no longer used.
Settings are saved under Mods\Config\tcs_modernoptions.ini.
Unconfirmed display changes revert after 15 seconds.
