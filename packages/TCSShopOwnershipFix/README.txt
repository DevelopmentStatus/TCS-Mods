Shop Ownership Fix 1.0.0

Close the game. Put TCSShopOwnershipFix-v1.0.0.zip directly into the game's Mods
folder and keep it compressed. Requires TCS Mod Loader and the supported x86
Steam PC game build.

When the native shop initializes or updates, characters already owned in your
collection are also shown as purchased in the shop. This removes false Buy
prompts and the shop's unpurchased presentation for those entries.

No studs, ownership flags, progression requirements, shop purchase save bits,
game archives or save files are changed. Unowned characters remain subject to
the game's normal unlock and purchase rules. Ships use those same rules.

Pause > Mod Settings > Shop Ownership Fix > Correct owned characters in shop
toggles the correction. The shop refreshes when its native update resumes.
Configuration is saved in Mods/Config/tcs_shopownership.ini.

To remove, close the game and remove this ZIP. The original shop behavior returns
on restart. Existing missing or incompatible icon textures are not repaired by
this mod; it corrects ownership presentation, not the icon assets themselves.
