TCS Character & Shop Extender 1.0.0

Optional plugin for TCS Mod Loader 1.8.0 or later and the supported Steam PC game.
Provides up to 1,000 registered characters and shop entries, expanded text/portrait
tables, and additional character progress in compatible .tcs-characters files.
These features are no longer built into d3d9.dll or bundled with the loader.

Installation:
1. Close the game and install TCS Mod Loader 1.8.0 or later.
2. Place this ZIP directly in Mods. Keep it compressed; do not extract it.
3. Run Manage Mod Priorities.cmd and choose Launch game, or run Prepare Mods.cmd.

Keep existing native saves and their .tcs-characters companions together.
The companion format and slot naming are unchanged from the built-in extender.
Story unlock rules, prices and stud balances are unchanged.

Restart required. Do not unload the DLL while the game is running.
Removing this ZIP disables extended support on the next preparation/launch.
Character overlays that require it are then refused, rather than loaded against
the native limits. Existing saves and companions are left intact.

This plugin is distributed separately because the detection-associated extender
code is optional. Separation does not establish that its antivirus detections
are false positives or remove those detections from the plugin itself.
