TCS Skip Splash 1.0.0
For the 32-bit Steam version of LEGO Star Wars: The Complete Saga.

INSTALL
Requires the TCS Mod Loader already installed beside LEGOStarWarsSaga.exe.
Copy TCSSkipSplash-v1.0.0.zip directly into the game's Mods folder.
Keep the ZIP compressed, then launch the game.

Skips the startup logos, legal splash and opening text display by selecting
LoadPerm's built-in synchronous loading path. Required startup assets still
load; a black screen may appear briefly while this completes. The title menu
and gameplay cutscenes remain available. No game files are patched on disk.
This also bypasses the startup language-selection page; existing language
configuration is retained. Configure the language before enabling this mod
if needed.

SETTINGS
Pause > Mod Settings > TCS Skip Splash > Skip splash (restart).
Changes take effect on the next game launch.
Config: Mods\Config\tcs.skipsplash.ini, [Settings] Enabled=1 or 0.

REMOVE
Close the game and remove TCSSkipSplash-v1.0.0.zip from Mods.
Other mods and saved games are unaffected.

COMPATIBILITY
Checks the original startup instructions and branch target before patching.
Refuses unsupported builds or a conflicting startup patch. Check
TCSModernOptions.log in the game folder if the plugin does not load.
